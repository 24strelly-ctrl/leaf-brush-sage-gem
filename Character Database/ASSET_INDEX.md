## Asset Generation Guidelines

### Priority Order
1. **Legendary Characters** - Highest priority for core system functionality
2. **Rare Characters** - Medium priority for specialized functions
3. **Common Characters** - Lower priority for utility functions
4. **Rare Soul Characters** - Special priority for mystical/cosmic functions

### Asset Types
- **Portrait**: Main character portrait for detailed character representation
- **Poster**: Promotional poster for marketing and showcase purposes
- **Avatar**: Small avatar for UI elements and profile pictures
