## Technical Specifications

#### **Image Requirements**
```
Technical specifications for all visual assets:

RESOLUTIONS:
- High-resolution: 300 DPI for print
- Web-optimized: 72 DPI for digital
- 4K ready: 3840x2160px for video backgrounds

FILE FORMATS:
- PNG: Transparent backgrounds, high quality
- JPG: Web-optimized, smaller file size
- SVG: Scalable vector graphics
- PDF: Print-ready documents

COLOR PROFILES:
- sRGB: Web and digital use
- CMYK: Print materials
- Pantone: Brand color consistency

DIMENSIONS:
- Square: 1080x1080px (Instagram, Facebook)
- Portrait: 1080x1920px (Stories, TikTok)
- Landscape: 1920x1080px (YouTube, web)
- Banner: Various ad sizes
```

#### **Brand Guidelines**
```
Visual brand consistency guidelines:

COLOR PALETTE:
- Primary: Deep purple (#2D1B4E)
- Secondary: Electric blue (#00D4FF)
- Accent: Gold (#FFD700)
- Background: White (#FFFFFF) and dark (#1A1A2E)

TYPOGRAPHY:
- Headlines: Modern sans-serif (Inter, Roboto)
- Body: Clean readable fonts (Open Sans, Lato)
- Accent: Bold statement fonts (Montserrat)

STYLE GUIDELINES:
- Clean, modern aesthetic
- Professional yet approachable
- High contrast for accessibility
- Consistent spacing and alignment
- Premium quality imagery
- Brand-consistent styling
```
