## Getting Started

### How do I start using the bot?
Getting started is easy:
1. **Search for the bot**: Find @AICharacterPromptsBot on Telegram
2. **Start the bot**: Send /start command to begin
3. **Choose your plan**: Select free or premium subscription
4. **Browse characters**: Use /characters to see available options
5. **Generate prompts**: Use /generate to create custom characters
6. **Get help**: Use /help for command reference

### What commands are available?
Available commands:
- `/start` - Initialize the bot and see welcome message
- `/help` - Display all available commands and features
- `/characters` - Browse the character database
- `/generate` - Create custom character prompts
- `/search` - Search for specific character types
- `/categories` - View character categories and filters
- `/premium` - Upgrade to premium subscription
- `/settings` - Customize your bot preferences
- `/share` - Share characters with other users

### Is there a cost to use the bot?
The bot offers:
- **Free tier**: 5 character generations per day

- **Trial period**: 7-day free premium trial
