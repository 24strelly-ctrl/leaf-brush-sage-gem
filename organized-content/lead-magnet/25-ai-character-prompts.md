## How to Use These Prompts

### For AI Image Generation
1. **Copy the visual description** from each character prompt
2. **Use with tools like**: Midjourney, DALL-E, Stable Diffusion
3. **Add style modifiers**: "photorealistic", "digital art", "cinematic lighting"
4. **Specify aspect ratio**: "--ar 16:9" for landscapes, "--ar 1:1" for portraits

### For Character Development
1. **Start with the archetype** to establish core identity
2. **Build personality** from the description and backstory
3. **Add skills and attributes** to create unique capabilities
4. **Determine relationships** with other characters in your story

### For Content Creation
1. **Match character to platform**: Use Legendary characters for premium content
2. **Scale appropriately**: Common characters for everyday content, Rare for specialized
3. **Create character arcs**: Progress from Common to Legendary through development
4. **Build character ecosystems**: Create relationships between characters
